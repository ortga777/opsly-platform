# Development Process

Opsly will be developed incrementally so the repository clearly shows how the product evolves.

## Milestones

- v0.1 — Product foundation and design system
- v0.2 — Application shell
- v0.3 — Authentication
- v0.4 — Operations dashboard
- v0.5 — Tasks, sales and products
- v0.6 — Opsly Pulse
- v0.7 — Opsly AI
- v0.8 — AWS integration
- v0.9 — Production hardening
- v1.0 — Competition release

## AI-assisted development

The project will document where the coding agent contributes to implementation, debugging, testing, infrastructure and iteration. Human decisions remain responsible for product direction, architecture and final validation.
