# Opsly Architecture

## Direction

Opsly is being designed as an AI-native business operations workspace.

## Initial layers

1. Web application
2. Application/API layer
3. Data layer
4. AI intelligence layer
5. AWS infrastructure
6. Observability

## Principles

- Secure by default
- Type-safe
- Accessible
- Responsive
- Observable
- AI-assisted, not AI-dependent
- Real functionality over visual-only demos

## Initial technology direction

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- PostgreSQL
- Prisma
- Amazon Bedrock
- AWS managed services
- GitHub Actions
